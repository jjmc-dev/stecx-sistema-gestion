# StecX - Sistema de Gestión de Repuestos y Mantenimiento

Este repositorio contiene la documentación web y el análisis inicial del proyecto **StecX**, desarrollado para la materia de Análisis y Diseño de Sistemas (INF - 162) de la Universidad Mayor de San Andrés (UMSA).

## 📌 Descripción del Proyecto
StecX es una empresa dedicada al mantenimiento y reparación de equipos de ofimática. Este proyecto se enfoca en el análisis y diseño de un sistema que resuelva el control descentralizado del inventario de repuestos y el registro de equipos asociados a municipios.

## 🚀 Tecnologías Utilizadas
*   HTML5
*   CSS3 (Custom Properties)
*   Bootstrap 5 (Framework de diseño frontend)
